# Portfólio Profissional - Elian Oliver

Um portfólio web moderno e responsivo, desenvolvido com as tecnologias mais atuais do desenvolvimento frontend. Destina-se a apresentar projetos, habilidades técnicas e facilitar contato com recrutadores e potenciais colaboradores.

**Live Demo:** [elian.dev.br](https://elian.dev.br/)

---

## 📋 Sobre

Este repositório contém o código-fonte de meu portfólio profissional. O projeto apresenta uma interface moderna, intuitiva e otimizada para oferecer a melhor experiência ao usuário. Todos os projetos destacados foram desenvolvidos com foco em qualidade de código, design responsivo e performance.

---

## 🎯 Características

- ✅ **Design Responsivo**: Otimizado para todos os tamanhos de dispositivo (mobile, tablet, desktop)
- ✅ **Animações Fluidas**: Transições e efeitos visuais com Framer Motion
- ✅ **TypeScript**: Código tipado para maior segurança e manutenibilidade
- ✅ **Componentes Reutilizáveis**: Arquitetura modular com shadcn/ui
- ✅ **Performance Otimizada**: Build rápido com Vite
- ✅ **Styling Moderno**: Tailwind CSS para estilização eficiente
- ✅ **Ícones Vetoriais**: Lucide React para ícones consistentes

## 🚀 Como Começar

### Pré-requisitos

Certifique-se de ter instalado em seu sistema:
- [Node.js](https://nodejs.org/) (v18 ou superior)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

### Instalação

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/elianoliver/Portfolio.git
   cd Portfolio
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

   A aplicação estará disponível em `http://localhost:5173`

### Build para Produção

Para gerar uma versão otimizada para produção:

```bash
npm run build
```

Os arquivos compilados serão salvos no diretório `dist/`.

### Verificação de Qualidade

```bash
# ESLint para análise estática de código
npm run lint

# Prévia de produção localmente
npm run preview
```
